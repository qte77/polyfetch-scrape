### Changed

- Documented the scope of the patchright crash retry (#183): it covers relaunching the
  browser between attempts, not the browser's first launch, which still raises the raw
  Patchright error on failure. A test now pins that `context.close()` raising on a dead
  connection is retried like any other whole-browser death.
