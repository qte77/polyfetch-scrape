### Added

- `fetch()` gains opt-in `stream_to=Path` (httpx and curl_cffi tiers): a 2xx body is
  written to disk in chunks instead of being held in memory, through a temp file in the
  target's directory that is moved onto the target only after a complete, non-empty
  transfer, so a failed download never leaves a partial file there. `Response` gains
  `saved_to`, `saved_size` and `saved_sha256`; `body` is `b""` when streaming. The
  patchright tier raises `FetchError`; an unfollowed 3xx is returned without saving; error
  bodies are read only up to the diagnostics excerpt; on the curl_cffi tier a streamed
  fetch, error bodies included, ends at about `timeout` like a buffered one, through
  libcurl's whole-transfer timeout plus a between-chunks check (#261). Python API only; no CLI flag yet.
