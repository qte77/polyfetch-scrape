### Added

- Opt-in full network log + SSE capture (#182): `RenderOptions.capture_network` / `render_session(capture_network=...)` record a bounded per-request log (url, method, resource type, status, failure reason, start/duration timing) onto `Response.network_log` / `RenderSession.network_log`, including `EventSource` (SSE) message frames nested under their request — the gap `capture_network_failures` doesn't cover. Uses a separate CDP session sending only `Network.enable`, never `Runtime.enable`/`Console.enable`/`Page.enable` (the leaks Patchright's own stealth model patches around); verified not to change page-visible automation signals and to coexist with HAR recording, `page.route`, and the existing `capture_network_failures`. Capped at 1000 request entries and 1000 SSE messages per session (`network_log_truncated` flips once a cap is hit); SSE `data` is truncated to 2 KB; never records request/response bodies or header values. Off by default. Python-API-only for now — no existing CLI flag shape fits a structured per-request log. Documented in USING.md, docs/api-reference.md, docs/architecture.md and a new `docs/scripting.md` recipe.
