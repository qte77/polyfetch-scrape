# Fallback-chain example targets — the hardest ToS-safe sites per tier, for
# demonstrating httpx -> curl_cffi -> Patchright (and the ceiling beyond it).
#
# "ToS-safe" = purpose-built scraping / anti-bot test sandboxes or fingerprint-echo
# services whose own terms or robots.txt permit automated testing. Each was probed
# with polyfetch on 2026-06 (the winning Response.backend is noted); live sites
# drift, so re-verify before relying on a specific tier outcome.
#
#   Run one:        uv run polyfetch fetch <url> --json        # shows status + backend
#   See the body:   uv run polyfetch fetch <url> --show-body
#
# Lines starting with '#' and blank lines are skipped (by both `--seeds-file` and
# `polyfetch bulk`), so you can run the whole ladder at once:
#   make probe_bulk FILE=examples/fallback-tier-targets.txt WORKERS=4

# --- Tier 1: httpx — open but non-trivial (structured HTML, pagination, forms) ---
# scrapethissite.com: its FAQ explicitly authorizes automated scraping (1 req/s,
# set a User-Agent). robots allows /pages/. Probed: 200 [httpx].
https://www.scrapethissite.com/pages/

# --- Tier 2: curl_cffi — TLS/JA3 fingerprint (echo services) ---
# These reflect your TLS fingerprint instead of blocking, so fetch() resolves them
# at tier 1; to SEE tier 2, call the curl_cffi backend and compare its JA3 to
# httpx's. tls.browserleaks.com/json is the endpoint curl_cffi's own README uses to
# verify impersonation. Probed: tls.peet.ws 200 [httpx].
https://tls.browserleaks.com/json
https://tls.peet.ws/api/all

# --- Tier 3: Patchright/Chromium — JS render (httpx gets only a JS-gated shell) ---
# scrapingcourse.com/javascript-rendering: self-labeled "JS Rendering Challenge";
# httpx returns 200 but the products appear only after JS runs. robots allows it
# (only /ecommerce/* is disallowed). Probed: 200 [httpx] with a JS-gated body.
# creepjs is the hardest JS-fingerprint battery (MIT; research/education) for
# exercising Patchright's stealth under scrutiny.
https://www.scrapingcourse.com/javascript-rendering
https://abrahamjuliot.github.io/creepjs/

# --- Ceiling: hardest ToS-safe — 403s ALL tiers, incl. headless Chromium ---
# These anti-bot / Cloudflare challenge pages return 403 to httpx, curl_cffi, AND
# headless Patchright (empirically verified — FetchError at status=403 every tier).
# They require a HEADED real browser / human takeover; see issue #59. robots allows
# them — they exist precisely to be tried.
https://www.scrapingcourse.com/antibot-challenge
https://www.scrapingcourse.com/cloudflare-challenge
